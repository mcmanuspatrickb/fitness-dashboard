Time Series Data Export

The Time Series export provides a detailed timeline of your tracked activity.

Files Included:
----------

moods.csv                             - Contains all data for this type.

Each entry has the following values:

    timestamp                         - Date and time at which the entry was logged.
    moods                             - A comma-separated list of moods recorded at the given timestamp. Examples include AMAZED, ANGRY, HAPPY, CALM, STRESSED, ENERGIZED, etc.
    feature_source                    - The feature on which the mood was logged. Examples include JOURNAL, MINDFULNESS, etc.
    data source                       - The origin or source of this data.
